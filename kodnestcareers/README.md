# KodNestCareers

Production-ready full-stack career platform.

## Tech Stack

- **Frontend:** Next.js (TypeScript)
- **Backend:** FastAPI (Python)
- **Database:** PostgreSQL
- **Cache:** Redis
- **Queue:** RabbitMQ
- **Workers:** Celery
- **Containerization:** Docker
- **CI/CD:** GitHub Actions

## Architecture

Modular, event-driven architecture with separate backend, frontend, workers, infra, and tests.

## Project Structure

See repository layout for `frontend/`, `backend/`, `workers/`, `infra/`, `scripts/`, `docs/`, and `tests/`.

## Getting Started

1. Copy `.env.example` to `.env` and configure.
2. Use Docker Compose for local development (see `docker-compose.yml`).
3. See `docs/` for detailed setup and runbooks.
